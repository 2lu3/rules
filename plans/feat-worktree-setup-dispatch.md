# worktree セットアップの固有スクリプト呼び出し

## User Prompt

共通実装である `scripts/setup-worktree.sh` が、必須引数として元リポジトリのパスと worktree リポジトリのパスを受け取り、その2つのパスをプロジェクト固有の `scripts/setup-worktree-*.sh` へ渡して呼び出すようにする。既存の Git repository root 自動検出処理は削除し、README に引数と固有スクリプトの使い方を記載する。

## 実装方針

- 引数が2つ以外の場合は使い方を表示して失敗させる。
- 2つのパスを検証して絶対パスへ解決し、worktree リポジトリを作業ディレクトリにする。
- `scripts/setup-worktree-*.sh` をシェルの glob 順に実行し、該当ファイルがない場合は成功扱いにする。
- 各固有スクリプトへ元リポジトリの絶対パスと worktree リポジトリの絶対パスを同じ順序で渡す。
- README に自動実行用の呼び出し形式、引数の意味、固有スクリプトの命名規則を追記する。

## 検証

- `bash -n scripts/setup-worktree.sh` で構文を確認する。
- 一時ディレクトリに元リポジトリ、worktree、複数の固有スクリプトを用意し、引数の伝播と実行順を確認する。
- 引数不足、存在しないパス、固有スクリプトがない場合、固有スクリプトが失敗する場合を確認する。
- README の説明と実装の呼び出し形式を照合する。
